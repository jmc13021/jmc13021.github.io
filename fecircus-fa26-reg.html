Conference Registration

Finite Element Circus — October 16-17, 2026

There is no registration fee to attend the Finite Element Circus. However, we ask that all attendees register in advance so the organizers can get an accurate headcount, especially for organizing the conference dinner. Also, please indicate if you will need to park at the event on the first day, Friday, so we can issue a pass (no charge for the pass, and parking on Saturday is open).

Please click the button below to fill out the registration form via Google Forms. It should only take a minute to complete.

Open Registration Form

If you have any questions or need to update your registration information later, please contact the organizers.
